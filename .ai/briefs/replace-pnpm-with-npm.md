# Replace pnpm with npm

> Status: done

## Objective

Migrate the repository from pnpm to npm. pnpm adds toolchain overhead (extra CI
step, separate action, lock-file format) for a project with no monorepo needs.
npm ships with Node.js and simplifies CI and onboarding.

## Context

### Why `.npmrc` is pnpm-only

The `only-built-dependencies[]=` array syntax (with `[]=`) is a pnpm-specific
extension to `.npmrc`. npm's own `.npmrc` doesn't support it and ignores it
silently, so the file is safe to delete. With npm, all packages are allowed to
run lifecycle scripts by default — the packages listed (esbuild, @rolldown/…,
@oxlint/…) will install correctly without any equivalent config.

### Why the `"pnpm"` block in `package.json` can be deleted

`package.json` lines 27–34:
```json
"pnpm": {
  "onlyBuiltDependencies": [
    "esbuild",
    "@rolldown/binding-win32-x64-msvc",
    "@oxlint/binding-win32-x64-msvc",
    "core-js"
  ]
}
```
This is pnpm's per-project opt-in for lifecycle scripts. npm doesn't read this
key. Since npm allows all lifecycle scripts by default, just delete the block.

### Vercel auto-detects the package manager

Vercel detects pnpm vs npm by presence of `pnpm-lock.yaml`. Once that file is
deleted and `package-lock.json` is present, Vercel switches to npm automatically.
No `vercel.json` change needed.

### GitHub Actions — ipca.yml change

Current `ipca.yml` (active) has these steps to replace:

```yaml
# REMOVE this step entirely:
- uses: pnpm/action-setup@v4
  with:
    version: 12

# CHANGE cache value in this step:
- uses: actions/setup-node@v4
  with:
    node-version: '22'
    cache: 'pnpm'          # → change to 'npm'

# CHANGE these commands:
- name: Instalar dependências
  run: pnpm install --frozen-lockfile   # → npm ci

- name: Executar seed-taxas.mjs
  run: pnpm exec node scripts/seed-taxas.mjs   # → node scripts/seed-taxas.mjs
```

`pnpm exec node` is just `node` when the package is already installed globally
(which Node.js is). Use `node` directly.

### Command mapping

| pnpm | npm equivalent |
|------|----------------|
| `pnpm dev` | `npm run dev` |
| `pnpm build` | `npm run build` |
| `pnpm test` | `npm test` |
| `pnpm test:coverage` | `npm run test:coverage` |
| `pnpm lint` | `npm run lint` |
| `pnpm exec vitest run <file>` | `npx vitest run <file>` |
| `pnpm exec tsx scripts/...` | `npx tsx scripts/...` |
| `pnpm exec node scripts/...` | `node scripts/...` |
| `pnpm install --frozen-lockfile` | `npm ci` |
| `pnpm install` | `npm install` |
| `pnpm db:generate` | `npm run db:generate` |
| `pnpm db:migrate` | `npm run db:migrate` |
| `pnpm db:studio` | `npm run db:studio` |

## Steps

1. **Generate `package-lock.json`**: Run `npm install` in the project root.
   This reads `package.json` (unchanged dependencies) and creates
   `package-lock.json`. Ignore any audit warnings.

2. **Delete pnpm artifacts**:
   - Delete `pnpm-lock.yaml`
   - Delete `.npmrc`

3. **Edit `package.json`**: Remove the `"pnpm": { ... }` block (lines 27–34).
   Result: `"devDependencies"` follows immediately after `"dependencies"`.

4. **Update `ipca.yml`** (`github/workflows/ipca.yml`):
   - Remove the `pnpm/action-setup@v4` step entirely
   - Change `cache: 'pnpm'` → `cache: 'npm'` in `setup-node`
   - Change `pnpm install --frozen-lockfile` → `npm ci`
   - Change `pnpm exec node scripts/seed-taxas.mjs` → `node scripts/seed-taxas.mjs`

5. **Delete `deploy.yml`** (`.github/workflows/deploy.yml`): The file is
   already marked OBSOLETE (GitHub Pages, superseded by Vercel). Delete it.

6. **Update `CLAUDE.md`** — Commands section: apply command mapping table above.

7. **Update `README.md`**: Apply command mapping to all pnpm occurrences.
   Also update "Node.js 22+ e pnpm 12+" → "Node.js 22+".

8. **Update script comments**: Run `grep -rn "pnpm" scripts/` and update each
   comment line with the npm equivalent. These are documentation-only lines,
   no logic changes needed.

9. **Update docs**:
   - `specs/001-controle-de-rateios/checklists/requirements.md` — any pnpm refs
   - `.ai/briefs/README.md` — `pnpm test` → `npm test` in the template
   - `.ai/deploy/deploy.md` — `pnpm install` / `pnpm build` references

## Constraints
